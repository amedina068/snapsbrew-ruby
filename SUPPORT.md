# Get help with the Snapsbrew Ruby SDK

One person maintains Snapsbrew and its SDKs. Answers to questions, issues and pull requests are not immediate. Use the correct place for each request, so that the maintainer can find it.

## Read the documentation

Read [README.md](README.md) for the use of this SDK. The documentation of Snapsbrew and of all the SDKs is at [snapsbrew.com/docs](https://snapsbrew.com/docs/sdks/overview).

## Ask a question

Ask a question in the [Q&A category of the Discussions](https://github.com/amedina068/snapsbrew/discussions/categories/q-a) of the app repository. Do not open an issue for a question.

Put these items in your question:

- The version of the SDK and the version of Ruby.
- The smallest code that shows what you tried.
- The error and its request ID, if you have them.

Never put a token, a signing key or another secret in a question.

## Report a bug or ask for a feature

If the problem is in the SDK, open an [issue in this repository](https://github.com/amedina068/snapsbrew-ruby/issues/new/choose) with the matching form.

If the problem is in the Snapsbrew server or in the API, open an [issue in the app repository](https://github.com/amedina068/snapsbrew/issues/new/choose).

## Report a security problem

Do not open a public issue or a discussion for a security problem. Read [SECURITY.md](SECURITY.md) and report the problem in private.
